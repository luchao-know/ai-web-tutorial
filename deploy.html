零成本部署你的网站

不懂代码？跟着教程走，10分钟让你的网站上线。全部免费。

🐙 GitHub Pages 部署（免费）

1

注册 GitHub 账号

打开 github.com，点击 Sign up，输入邮箱和密码完成注册。

2

创建仓库

点击右上角 + → New repository
仓库名填：你的用户名.github.io（例如 luchao-know.github.io）
设置为 Public，勾选 Add a README file。

3

下载 GitHub Desktop

下载 GitHub Desktop，登录后把你的仓库 Clone 到电脑上。

4

上传网站文件

把你准备好的 index.html 等文件复制到仓库文件夹中。
在 GitHub Desktop 里提交（Commit）并推送（Push）。

5

访问你的网站

打开浏览器，输入 https://你的用户名.github.io
稍等 1-2 分钟，你的网站就上线了！

▲ Vercel 部署（免费，推荐）

1

注册 Vercel

打开 vercel.com，点击 Sign Up，用 GitHub 账号登录。

2

导入 GitHub 仓库

点击 Add New → Project → Import Git Repository
选择你的网站仓库，点击 Import。

3

配置并部署

Framework Preset 选 "Other"
点击 Deploy，等待 30 秒就部署完成了！

4

绑定域名（可选）

在项目设置中点击 Domains，输入你的域名。
在域名服务商处添加 CNAME 记录到 cname.vercel-dns.com。
