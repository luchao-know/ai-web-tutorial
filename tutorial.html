OpenClaw 建站完整教程

零基础也能学会。从注册账号到用 OpenClaw 建站部署，10 分钟让你的网站上线。

🤖 什么是 OpenClaw？

OpenClaw 是一个开源的 AI 助手平台，可以运行在你的电脑上。
它能帮你做很多事情：写代码、生成内容、管理文件、操控浏览器……
最关键的是：你可以跟它对话，让它帮你写网站代码，然后一键部署到 GitHub Pages！

→ 去 GitHub 看 OpenClaw 源码
1

注册 GitHub 账号

GitHub 是全球最大的代码托管平台，也是免费部署网站的地方。

  1. 打开 github.com
  2. 点击右上角 Sign up
  3. 输入邮箱、密码、用户名（例如：yourname）
  4. 验证邮箱，完成注册
💡 建议用户名用英文，因为后面部署的网站域名是 你的用户名.github.io
2

安装 OpenClaw

OpenClaw 可以安装在 Mac / Windows / Linux 上。

⚠️ 需要先安装 Node.js（版本 ≥ 18）

安装 Node.js：

打开 nodejs.org，下载 LTS 版本安装即可
安装完成后打开终端（Terminal），输入：

# 测试是否安装成功
node -v
npm -v

安装 OpenClaw：

# 打开终端，输入以下命令
npm install -g openclaw

# 测试是否安装成功
openclaw status
3

用 OpenClaw 生成网站代码

OpenClaw 启动后，在聊天窗口告诉它你想要什么样的网站：

// 在 OpenClaw 聊天窗口输入：

"帮我做一个个人博客网站，要求：
- 深色主题，现代化设计
- 响应式布局，手机也能看
- 包含首页、文章列表、关于我三个页面
- 导航栏固定顶部，毛玻璃效果
- 用 HTML + CSS + JavaScript 实现"

OpenClaw 会自动生成完整的网站代码文件。你可以让它反复修改直到满意。

4

创建 GitHub 仓库并推送代码

  1. 打开 GitHub，点击 + → New repository
  2. 仓库名填：你的用户名.github.io（例如 luchao-know.github.io）
  3. 设置为 Public，其他默认，点击 Create
  4. 把 OpenClaw 生成的文件上传到仓库
# 或者用 Git 命令行推送
git clone https://github.com/你的用户名/你的用户名.github.io.git
cd 你的用户名.github.io
# 把 OpenClaw 生成的 index.html 等文件复制进来
git add .
git commit -m "我的第一个网站"
git push
5

网站上线！绑定自定义域名

代码推送后等 1-2 分钟，你的网站就上线了！

访问：https://你的用户名.github.io

绑定自定义域名（买了域名后）：

  1. 在 GitHub仓库 → Settings → Pages
  2. 在 Custom domain 输入你的域名（如：example.com）
  3. 去域名服务商（阿里云/腾讯云/Cloudflare）添加 CNAME 记录
  4. CNAME 指向：你的用户名.github.io
  5. 等待 DNS 生效（几分钟到几小时）
💡 GitHub Pages 自动提供 HTTPS 证书，无需额外配置

❓ 常见问题

Q: 需要会编程吗？

完全不需要。OpenClaw 会用自然语言跟你交流，你只负责告诉它你想要什么。

Q: GitHub Pages 免费吗？

完全免费。不限流量，不限空间，自动 HTTPS。唯一的限制是仓库不能超过 1GB。

Q: OpenClaw 收费吗？

OpenClaw 本身免费开源。如果你用 AI 接口（如 DeepSeek/OpenAI），需要自己充 API 费用。
