手把手部署 OpenClaw

最简单的终端部署教程，Mac / Android / iPhone 全覆盖。永久免费公开。

1️⃣ 安装 Homebrew

打开终端，粘贴：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2️⃣ 安装 Node.js

brew install node

验证：node -v

3️⃣ 安装 OpenClaw

npm install -g openclaw

4️⃣ 启动

openclaw
