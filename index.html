手把手教你部署 OpenClaw

用最简单的终端命令，把 OpenClaw 部署到你的设备上。免费公开，新手友好。

1️⃣ 安装 Homebrew（包管理器）

打开终端，粘贴下面这行命令，回车：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

2️⃣ 安装 Node.js

Homebrew 装完后，继续在终端输入：

brew install node

验证安装：node -v 应该显示版本号，比如 v22.x

3️⃣ 安装 OpenClaw

一行命令搞定：

npm install -g openclaw

4️⃣ 启动 OpenClaw

装好后在终端输入：

openclaw

浏览器打开显示的地址（通常是 http://localhost:18789），看到网页界面就成功了！

💡 常用命令

查看状态：openclaw status

查看帮助：openclaw help

更新版本：npm update -g openclaw

1️⃣ 安装 Termux

打开手机浏览器，去 F-Droid 搜索安装 Termux（不要从Google Play装，那个版本太旧）。

2️⃣ 更新包管理器

打开 Termux，输入：

pkg update && pkg upgrade -y

3️⃣ 安装 Node.js

继续在 Termux 里输入：

pkg install nodejs -y

4️⃣ 安装 OpenClaw

npm install -g openclaw

5️⃣ 启动

openclaw

手机上会显示本地地址，在浏览器打开就能用了。建议搭配 tmux 让它在后台运行。

1️⃣ 安装 iSH（终端模拟器）

去 App Store 搜索 iSH Shell，免费下载安装。这是 iPhone 上最好用的终端。

2️⃣ 更新软件源

打开 iSH，输入：

apk update && apk upgrade

3️⃣ 安装 Node.js

apk add nodejs npm

4️⃣ 安装 OpenClaw

npm install -g openclaw

5️⃣ 启动

openclaw

在 iPhone 的 Safari 浏览器打开显示的地址，就可以访问了。回到桌面 iSH 会在后台继续运行。
